# 모바일 옥구알리미 이용 방법

접속: https://okgu-mobile.rlasksk030.workers.dev/

## 처음 열기
1. 아이폰은 Safari, 갤럭시·안드로이드는 Chrome으로 주소를 엽니다.
2. 학교 업무 시트를 이용하는 구글 계정으로 로그인합니다. 현재는 등록된 시험 계정만 로그인할 수 있습니다.
3. 아이폰: 공유 → 홈 화면에 추가. 갤럭시: ⋮ 메뉴 → 앱 설치 또는 홈 화면에 추가.
4. 홈 화면의 옥구알리미 아이콘으로 엽니다.

## 일정 보기와 편집
- 오늘: 오늘 일정과 내일 미리보기.
- 일정: 3일·주간·월간 보기. 날짜를 선택하면 상세 목록 표시.
- 검색: 일정명·학년·담당자·장소의 단어를 검색.
- 설정: 글자를 크게 보고, 내 이름을 입력해 이름이 적힌 일정만 모아보기.
- 새 일정은 + 버튼. 기존 일정은 목록에서 눌러 수정 또는 삭제.
- 저장·삭제 전 확인 창을 확인합니다. 실제 학교 업무 시트에 반영됩니다.
- 동시에 같은 일정을 시트·확장프로그램·모바일에서 수정하는 것은 피합니다.
- 저장 중 연결이 끊기면 같은 내용을 다시 새로 입력하지 말고 설정 → 저장 결과 확인을 누릅니다.

## 일정 알림
1. 홈 화면 앱에서 설정 → 이 휴대폰에서 알림 받기 → 허용.
2. 필요한 시간대를 켜고 한국 시간으로 시간을 지정한 뒤 설정 저장하기.
3. 즉시 알림 테스트 또는 1분 후 테스트를 누릅니다. 같은 분의 중복 시험 요청은 하나로 처리됩니다.
4. 알림 연결 확인에서 발송 상태를 볼 수 있습니다. ‘서비스에 전달’은 발송 서비스 접수이며, 휴대폰에서 실제 표시됐는지는 알림함에서 확인합니다.
5. 1분 후 테스트는 다음 예약 실행에서 처리되므로 약 1~2분 뒤 도착할 수 있습니다. 여러 기기가 같은 시간에 요청하면 순서대로 발송됩니다.
6. 기기별로 알림을 꺼야 할 때는 이 기기 알림 끄기. 로그아웃하면 그 기기의 알림 연결도 해제됩니다.

아이폰 알림은 iOS 16.4 이상의 홈 화면 웹앱에서 지원합니다. 실제 기기 설치·잠금 상태 수신 확인은 아직 필요합니다. 알림이 안 오면 휴대폰의 알림 허용·집중 모드와 앱의 알림 연결 상태를 확인합니다.

현재 Google 로그인 앱은 Testing 상태로, 연결이 약 7일 뒤 만료될 수 있습니다. 앱에서 로그아웃 후 다시 로그인하면 연결할 수 있습니다. 정식 사용 전환·교직원 계정 사용 범위는 별도 확정이 필요합니다.
